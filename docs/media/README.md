# Demonstration media and credits

These screenshots and animations show the VisionGuidedPick UI and Isaac Sim
scene. They illustrate product operation and are not benchmark reports.

| File | Contents |
| --- | --- |
| [factory-scene.png](factory-scene.png) | Conveyor, two Panda arms, RGB-D cameras and bins |
| [teach-target.jpg](teach-target.jpg) | Target mask editing and separate dataset uploads |
| [observe.jpg](observe.jpg) | Instance segmentation, shared IDs and gantry point cloud |
| [observe-segmentation-cloud.gif](observe-segmentation-cloud.gif) | Observe masks, 3D bounds and motion-aligned point cloud |
| [auto-pick-grasp.gif](auto-pick-grasp.gif) | Wrist feeds, planned grasp overlay and task phases |

The animations are sampled at 5 FPS for display; this is an encoding rate.
UI screenshots may show an earlier layout. Planned overlays do not represent
contact-force measurements. No raw recording archive or training dataset is included.

Media depicts project-authored content, NVIDIA robot/camera assets and materials,
and Stanford Bunny derivatives. Credit: Stanford University Computer Graphics
Laboratory, Greg Turk and Marc Levoy. Preserve the
[Stanford source conditions](https://graphics.stanford.edu/data/3Dscanrep/#acknowledge),
[third-party notices](../../THIRD_PARTY_NOTICES.md) and
[asset provenance](../release/asset-provenance.md). The project's MIT grant covers
original contributions without relicensing depicted third-party content.
